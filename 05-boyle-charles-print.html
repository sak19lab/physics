今日のゴール

  • 圧力の正体を、気体分子の運動と結びつけて説明できる
  • ボイルの法則・シャルルの法則を使って計算できる

OPENING

押せば押すほど、なぜ重くなる？

翔太は自転車のタイヤに、空気入れで空気を入れていた。

「あれ、最初は軽かったのに、空気を入れれば入れるほど、ポンプを押すのが重くなってきた……なんでですか？」

先生「いいところに気づいたね。それは『圧力』の正体と関係している。今日は、気体の分子たちがどう暴れているかを見ていこう」

STORY

圧力の正体

SCENE 01

先生「気体は、目に見えない分子が容器の中を飛び回っている。圧力は、その分子が壁にぶつかる『勢い』の合計なんだ」

先生「分子がたくさんぶつかるほど、勢いよくぶつかるほど、圧力は大きくなる」

KEY POINT

圧力P［Pa］は、気体分子が容器の壁にぶつかる勢いの合計。分子の数（密度）が多いほど、動きが激しい（温度が高い）ほど、圧力は大きくなる。

MEMO — 身の回りで「圧力が高い／低い」を感じる場面を挙げてみよう

第5回　気体のギモン！押しつぶすとどうなる？（ボイル・シャルルの法則） 1 / 4
SCENE 02

先生「じゃあ、ピストンを押して体積を半分にしたら、圧力はどうなると思う？」

翔太「分子の数は変わらないのに、部屋が半分になったら……ぶつかる回数が増えそうです」

先生「その通り！　体積を半分にすると、同じ数の分子がより狭い空間に押し込められて、壁にぶつかる頻度が2倍になる。だから圧力も2倍になるんだ」

ボイルの法則のイメージ：体積を小さくすると、分子が壁にぶつかる頻度が増える

KEY POINT

ボイルの法則：温度が一定のとき、気体の圧力Pと体積Vは反比例する。
P × V ＝ 一定　→　P1V1 ＝ P2V2

第5回　気体のギモン！押しつぶすとどうなる？（ボイル・シャルルの法則） 2 / 4

STORY — 温度を上げても、圧力は変わる

あたためると、なぜ膨らむ？

SCENE 03

先生「今度は体積を変えずに、温度を上げてみよう。分子はどうなる？」

翔太「あたためられて……分子が激しく動くようになる？」

先生「そう。温度が上がると分子の運動が激しくなって、壁にぶつかる勢いが増す。体積が一定なら圧力が上がり、圧力を一定に保つなら体積がふくらむ」

先生「たとえば体積を変えずに、27℃から127℃にあたためたら？　絶対温度に直すと？」

翔太「27＋273＝300K、127＋273＝400Kですね」

KEY POINT

シャルルの法則：圧力が一定のとき、気体の体積Vと絶対温度Tは比例する。
VT ＝ 一定　→　V1T1 ＝ V2T2

SCENE 04

先生「この2つを合体させると、圧力・体積・温度のどれが変わっても成り立つ法則になる」

KEY POINT

ボイル・シャルルの法則：
PVT ＝ 一定　→　P1V1T1 ＝ P2V2T2

TEACHER'S NOTE

今回の「分子が壁にぶつかる勢い」は比喩的なイメージ。圧力を力積や運動量変化から厳密に導出する計算は、物理基礎の範囲では扱わない。この直感レベルの理解を土台に、次の計算練習に進む。

🎈 P1＝1.0×10⁵Pa、V1＝6.0L → V2＝2.0L（温度一定）

P1V1＝P2V2 → P2＝3.0×10⁵Pa

🌡️ V1＝3.0L、27℃（300K）→127℃（400K）（圧力一定）

V1T1＝V2T2 → V2＝4.0L

🚲 P1＝2.0×10⁵Pa、27℃（300K）→57℃（330K）（体積一定）

P1T1＝P2T2 → P2＝2.2×10⁵Pa

🎈 P1＝2.0×10⁵Pa、V1＝3.0L、27℃（300K）→P2＝1.0×10⁵Pa、－23℃（250K）

P1V1T1＝P2V2T2 → V2＝5.0L

第5回　気体のギモン！押しつぶすとどうなる？（ボイル・シャルルの法則） 3 / 4

SUMMARY

気体のギモン（解答例）

圧力の正体気体分子が壁にぶつかる勢いの合計。分子の数や速さが大きいほど圧力は大きい
ボイルの法則温度が一定のとき、PV＝一定（圧力と体積は反比例）
シャルルの法則圧力が一定のとき、VT＝一定（体積と絶対温度は比例）
ボイル・シャルルの法則PVT＝一定（どんな状態変化でも成り立つ）

ONE LINE

体積を小さくすれば圧力は上がり、温度を上げても圧力は上がる。ぜんぶ「分子の勢い」で説明できる。

MEMO — 高い山の上でお菓子の袋がふくらむ理由を、気体の法則で考えてみよう

確認テスト

約5〜10分 · 解答・解説付き（教員用）

01 基礎

気体の圧力の正体として正しい説明はどれか。

  • 気体分子が容器の壁にぶつかる勢いの合計である
  • 気体の重さそのものである
  • 気体の色の濃さである
  • 気体分子の数とは無関係である
解説圧力は、気体分子が壁にぶつかる勢いの合計。分子の数や速さが大きいほど圧力は大きくなる。

02 基礎・計算

温度一定で、圧力1.0×10⁵Pa・体積6.0Lの気体を、体積2.0Lまで圧縮した。圧力P₂は何Paか。

  • 1.0×10⁵Pa
  • 2.0×10⁵Pa
  • 3.0×10⁵Pa
  • 6.0×10⁵Pa
解説P1V1＝P2V2より、1.0×10⁵×6.0＝P2×2.0、P2＝3.0×10⁵Pa。

03 応用・計算

圧力一定で、体積3.0L・300Kの気体を400Kまであたためた。体積V₂は何Lか。

  • 2.25L
  • 3.0L
  • 4.0L
  • 5.0L
解説V1T1＝V2T2より、3.0300＝V2400、V2＝4.0L。

04 応用・記述

体積を一定に保ったまま気体の温度を上げると、圧力はどうなるか。理由とともに説明しなさい。

解答例温度が上がると気体分子の運動が激しくなり、壁にぶつかる勢いや頻度が増えるため、圧力は大きくなる。

05 応用

高い山に登ると、お菓子の袋がふくらむことがある。その理由として最も適切なのはどれか。

  • 山の上は外の気圧が低く、袋の中の圧力とのバランスがくずれて袋がふくらむから
  • 山の上は気温が高いから
  • 袋の中の気体分子の数が増えるから
  • 山の上では重力が弱くなるから
解説標高が上がると外の気圧（大気圧）が下がる。袋の中の圧力は変わらないので、外からの圧力が減った分、袋の中の気体が膨張してふくらむ。
